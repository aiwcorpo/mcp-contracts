# mcp-contracts

This artifact has no Java API: it packages the contract files of the MCP platform (OpenAPI, JSON Schema, Cedar schema,
WireMock stubs) as classpath resources under `mcp-contracts/`. There is no javadoc to generate; Maven Central requires a
javadoc jar for every jar, so this file stands in for it.

Documentation: https://github.com/aiwcorpo/mcp-contracts#readme
